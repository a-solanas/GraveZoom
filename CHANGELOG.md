# Changelog

## 1.3.0

- Grave Zoom now supports integration with GK2 Mod Framework.

## 1.2.2

- Controller triggers (L2/R2, LT/RT, ZL/ZR) can be used for zoom.
- Buttons are shown with your controller's own names.
- Default controller buttons: right trigger zooms in, left trigger zooms out.

## 1.2.1

- Controller support.
- New setting to ignore the controller in menus.
- Simpler zoom code, with tests.

## 1.1.0

- First public release.
- Zoom in and out with hotkeys, with an on-screen zoom readout.
- Settings in the F1 menu.
